## Featured Projects

### 🌍 [Bhu-Drishti — SIH Project](https://github.com/Ishant-Mishra/sih-project)
A land-use and land-records intelligence platform concept for research and policy decision support in India. It brings together land-related data, geospatial exploration, research, and AI-assisted analysis.

**Focus:** React, TypeScript, Node.js, PostgreSQL/PostGIS, data visualisation, AI-assisted analysis.

### 🎬 [Movie Recommender System](https://github.com/Ishant-Mishra/Movie-Recommender-System)
A content-based movie recommendation app that uses text features and cosine similarity to suggest films, with a Streamlit interface and TMDB movie details.

**Focus:** Python, Pandas, scikit-learn, Streamlit, API integration.

### 🧠 [Machine Learning Practice](https://github.com/Ishant-Mishra/Machine-Learning)
A growing collection of notebooks and experiments covering linear regression, gradient descent, model evaluation, PCA, and Python data libraries.

**Focus:** Python, NumPy, Pandas, Matplotlib, Seaborn, scikit-learn.

### 🧪 [COVID Symptom Checker — Educational ML Experiment](https://github.com/Ishant-Mishra/COVID-Symptom-Checker)
A notebook-based Decision Tree classification exercise using synthetic symptom data to practise preprocessing, model evaluation, feature importance, and visualisation. **It is not a medical diagnostic tool.**

**Focus:** Python, Pandas, scikit-learn, Decision Trees.
